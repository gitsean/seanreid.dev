Home Server

This site used to run on a cloud server. It now runs on a small computer at my house, and that's been a fun way to learn more about networking and security.

  • The server sits on its own isolated network segment behind a dedicated firewall. It can reach the internet, but it can't start a connection to anything else on my home network.
  • All traffic comes in through Cloudflare. The firewall only accepts web traffic from Cloudflare's network, so my home IP isn't published and direct scans are dropped.
  • Traffic is encrypted end to end, including the hop between Cloudflare and the server.
  • Deploys run through a GitHub Actions runner on the server itself. It only makes outbound connections, so nothing extra has to be opened to the internet.
  • The server is locked down with a host firewall, automatic security updates, key-only SSH from inside the house, and fail2ban.
  • A nightly job pulls my Strava activity into a database and publishes a summary to the Fitness page.

I've just scratched the surface and I'm looking forward to finding more uses for it.

Beach Cruiser Build

For about a year I'd had an itch to build a beach cruiser. One weekend I found a frame on Facebook Marketplace that was perfect for what I wanted. It was rusted and the components were shot. Only the frame, the handlebars, and a couple of other parts were worth saving.

I found a second cruiser with better parts, although its freewheel had a problem. I brought both bikes home, took them apart, and started putting one good bike together. I took the freewheel apart, cleaned it, greased it, and reassembled it. It's a simple but elegant design, and the repair worked perfectly.

In a couple of short days the bike was together and I took it for a spin. It has a smooth, relaxed ride that's perfect for a lazy trip into town. I can't wait to ride it more.
